# {{product}} brain

Product knowledge base for humans and AI agents, maintained with the `pb` (project-brain) Claude plugin.

- Start here: [`index.md`](index.md) · [`glossary.md`](glossary.md) · rules in [`AGENTS.md`](AGENTS.md)
- `functional/` features and concepts · `technical/` modules, interfaces, environments · `epics/` Jira epics in progress · `decisions/` · `open-questions/`
- `digests/` what the nightly routine ingested · `raw/` text extracted from uploaded files

Generated files (`index.md`, `glossary.md`, `context/`) are refreshed by every save to the `docs/brain` branch, where the brain lives; a PR from `docs/brain`, kept open by pb, brings it to the default branch.
